Change the stage and the process jumps sections immediately — that's the whole point of routing on one field. Set a V1 process to V2 native and it leaves the migration list for Active work; set it to To be retired and it goes the other way. The 28 live V1 processes land in V2 migration, which is now honestly what that tab is: everything not yet V2-native, pending a migrate-or-retire call.

2What this must not break: the All-Hands report

I am not touching isV2Relevant(). That function also feeds lib/reports/allhands-loader.ts — the live All-Hands report at /reports/v2-migration. Widening it to "everything not V2-native" would pull 28 live V1 processes into the migration funnel and overstate the migration programme in a deck the team presents. So Delivery gets its own sectionFor(row) and the report keeps its stricter, evidence-based definition. Two consumers, two questions, two functions.
